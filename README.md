# Hashtag Entrega — Plataforma de Gestão

Este repositório guarda apenas a versão de testes da nova interface e do sistema de gestão de motoboys desenvolvido para a Hashtag, focado na operação logística em todo o Brasil. O código original e as credenciais de produção são confidenciais e ficam em um repositório privado.

- **Acesso:** Disponível via painel web para avaliação de interface e fluxos.
- **Funcionalidades em teste:** Roteirização inteligente, controle de fila de entregadores, monitoramento de pedidos por status e métricas operacionais.

Cada atualização publicada neste ambiente contempla melhorias visuais e estruturais para validação antes da integração no sistema principal.
